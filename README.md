# iot-dashboard

Health monitoring system for industrial conveyor belts

## Download

git clone https://codefloe.com/ma-writes/iot-dashboard.git

or

git clone ssh://git@codefloe.com/ma-writes/iot-dashboard.git

or 

paste this in browser: https://codefloe.com/ma-writes/iot-dashboard/archive/main.zip

## Commands

cd iot-dashboard
php -S localhost:8000
cd digital_twin-main
npm install
npm run dev

(open http://localhost:8000 in browser)
(npm should be ruuning on http://localhost:5173)
