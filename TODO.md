Development sequence:

Create the static dashboard layout.
Add responsive styling.
Add hardcoded demo values.
Replace hardcoded values with the PHP demo API.
Add polling every 2–5 seconds.
Add thermal colors and alert thresholds.
Add chart history.
Add SVG digital twin interactions.
Add MySQL tables and CRUD pages.
Replace demo API logic with database queries.
Connect real sensors through HTTP, serial communication, or MQTT.
Add authentication, logging, and deployment hardening.


For the first demonstration, the most important features are:

A professional control-room layout
Clearly visible system health
Thermal map with changing colors
Live-looking vibration chart
Digital twin with component states
Alerts and sensor status
Responsive design
Data refresh without reloading the page


Avoid connecting hardware until these screens and API responses are stable. The demo generator should imitate the same JSON format that the real sensors will eventually provide.
